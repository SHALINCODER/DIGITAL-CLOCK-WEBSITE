# Digital Clock Program

A simple, elegant real-time digital clock built with vanilla HTML, CSS, and JavaScript.

## Description

This project displays a live digital clock that updates every second, showing the current time in HH:MM:SS format. It features a modern dark theme with a clean, centered interface.

## Features

- 🕐 Real-time clock display
- ⏱️ Updates every second
- 🎨 Modern dark theme design
- 📱 Responsive layout
- ✨ Clean and minimalist UI

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Styling and layout
- **JavaScript (Vanilla)** - Clock logic and DOM manipulation

## How It Works

The clock uses JavaScript's `Date` object to fetch the current time and updates the display every second using `setInterval()`. The time is formatted with leading zeros using `padStart()` for consistent HH:MM:SS formatting.

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. The clock will automatically display and update in real-time
